# Understanding ROC and AUC

Welcome to this step-by-step guide to understanding Receiver Operating Characteristic (ROC) curves and Area Under the Curve (AUC).

## What will you learn?

This guide will introduce:

1. Binary classification and confusion matrices.
2. True Positive Rate (TPR) and False Positive Rate (FPR).
3. How ROC curves are constructed.
4. How AUC measures model discrimination.
5. Practical examples using machine learning.

## Introduction

ROC and AUC are important evaluation tools for classification models in machine learning.
